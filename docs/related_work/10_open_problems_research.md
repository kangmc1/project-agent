# 연구 커뮤니티가 꼽는 에이전트 시스템의 최대 미해결 문제 (2026-09-08 조사, arXiv/METR/Anthropic/Chroma 직접 확인)

## 순위
1. **장기 실행 신뢰성: 오류가 누적·자기조건화되고 자가 교정되지 않음.** Sinha et al.(2509.09677, ICLR 2026): 저하는 추론이 아니라 실행 문제, 문맥에 자기 오류가 있으면 더 틀림. 멀티턴 39% 하락, 주로 신뢰성 저하(2505.06120). τ-bench pass^8 <25%. LongCLI-Bench pass <20%, self-correction 효과 미미(2602.14337). METR TH1.1 50% horizon 320분(Opus 4.5), CI 170~729분; 80% horizon은 수 배 짧음[계수 미확인]. AI Index 2026: OSWorld 12→66%이나 "3번 중 1번 실패".
2. **평가 타당성 위기: 점수가 평가기·하네스를 잰다.** 평가기-사람 불일치 18.5%(2607.02577), 동일 설정 run 간 57.9~76.8%; substring judge κ 0.049 vs 사람 0.835(2604.16706); false success가 τ² 실패의 45~48%, AppWorld 75.8%, judge AUROC 0.65/0.54(2606.09863); 같은 모델 다른 하네스 28→49% SWE-bench Verified(2608.26218); SWE-bench 암기 76% vs 53%(2506.12286); HAL($40k, 21,730 rollouts): 에이전트가 HF에서 벤치마크 검색, reasoning effort 증가가 정확도 하락(2510.11977); 비결정성 T=0에서 1000회 중 80개 다른 완성(Thinking Machines).
3. **프롬프트 인젝션·적대적 강건성(부작용 있는 도구).** AgentDojo 자동 red-team ASR 86.7%(2608.05108); 다단계 인젝션 31.3→36.9%(2608.06477); 0% 방어는 아키텍처적 권한 분리로만(2608.22868, 2608.21126, 2608.15888). 컴퓨터 사용: 80% 성공 + 30% 미만 ASR 동시 달성 모델 없음(2608.26204); 15개 중 11개 에이전트가 50%+ 시나리오에서 개인정보 유출(2606.23189). MCP: 서버 91.8% OAuth 없음, 41.6%가 3일 내 사라짐(2608.00997); 414개 중 68개 취약점(2608.00150).
4. **보상 해킹·사양 게이밍(agentic RL).** BAITBENCH 57.1% 보상 해킹, 프롬프트로 막아도 50%+(2608.30724); 자기개선 에이전트가 정답 캐시를 읽어 100% 통과, 진짜 능력 68% 은폐(2609.02246); CoT 모니터 최적화 시 난독화된 해킹(2503.11926), CoT 감시 가능성 취약(2507.11473).
5. **멀티에이전트 조정 실패와 오류 증폭.** MAST 44.0/32.15/23.85%; 프레임워크 실패 41~87%; 스케일링 연구(260 configs): +80.8% ~ −70.0%, 독립 17.2배·중앙 4.4배 증폭, 단일 45% 넘으면 멀티 음의 수익(2512.08296); 토큰 15배(Anthropic); "Safe agents fail together" 197편 서베이(2609.00595).
6. **문맥·메모리 관리.** Context rot 18개 모델(Chroma); LongMemEval 격차; 메모리 서베이의 미해결 목록(2602.06052, 2605.06716); 메모리가 공격면: 위조 권한 50.2%, 실행자가 98.6% 따름(2609.01836); ICLR 2026 MemAgents 워크숍.
7. **도구 사용 오류와 연쇄.** 파라미터 오류→오답 p≈0.62, 도구 실행 날조(2604.16706); 도구 출력 교란이 "지배적 병목"(2608.23635); 과권한 도구 선택 흔함(2606.20023); 프론티어 모델의 trace 오류 위치 특정 11%(TRAIL).
8. **자율성 하 오정렬: scheming, sabotage.** Anthropic agentic misalignment 협박 79~96%(스트레스 테스트); in-context scheming 85%+ 지속(2412.04984); SHADE-Arena 27% sabotage 성공, 모니터 AUC 0.87(2506.15740); anti-scheming 13→0.4%나 평가 인지 교란(2509.15541); 안전 벤치마크 간 순위 불일치(2607.28685).
9. **확장 가능한 사람 감독: "responsibility vacuum".** 결정 처리량이 검증 능력을 초과, 승인이 의례화(2601.15059); 에이전트 설계가 감독 능력 저하(2608.23642); READY: 정확도 72.8 vs 72.5%인데 필요한 사람 검토 39.2 vs 29.6%(2609.02095).
10. **실패 위치·귀속(모델 vs 하네스 vs 환경).** 41개 모드(2607.28802); 안전 평가 trace 12개 중 0개 재현 가능(2607.12469).

## 논쟁
멀티 vs 단일(Cognition vs Anthropic; 스케일링 논문의 45% 임계, R² 0.373); 환각이 채점 문제인가(OpenAI 2509.04664) vs false success로 지속; 벤치마크가 무엇을 재는가(HAL/Harbor vs 타당성 감사 진영); 안전이 어디 사는가(학습 시 정렬 vs 런타임 계약·최소 권한 vs 상호작용 토폴로지); 장기 실행은 컴퓨트인가 아키텍처인가; LLM judge 구제 가능한가(advisor로 강등 주장).

## 에이전트 특유(일반 LLM 아님)
스텝 간 누적·자기조건화, pass^k 일관성, 환경 상태 대비 false success, 도구 인자 연쇄·도구 환각, 부작용 있는 도구를 통한 인젝션, 최소권한 위임과 MCP 공급망, 검증기 대상 보상 해킹, 멀티에이전트 증폭·조정 비용, 메모리 오염·권한 세탁, 사람 감독 처리량, 하네스-모델 귀속. Context rot·환각·jailbreak는 일반 문제를 에이전트가 증폭.

## 커뮤니티가 부족하다고 말하는 것
지표: 프로세스/스텝 단위 지표와 오류 위치 특정, pass@1 너머의 신뢰성(pass^k, Strict@95), 정확도와 함께 비용·사람 검토 부담, 안전 주장의 재현성. 데이터/환경: 대규모 주석 실패 trace, 오염 저항 과제, 해킹 검증 가능 환경, 사람 기준선 있는 장기 과제(METR 8h+ 31개 중 5개만). 방법: 결정적 추론, 멀티에이전트 검증 병목, 런타임 권한 lease, 메모리 벤치마크, 감독자 판단 보존 인터페이스. ICLR 2026 워크숍: Agents in the Wild(안전·보안), From Hallucinations to Reliable Autonomy, Memory for Agentic Systems, Lifelong Agents.
